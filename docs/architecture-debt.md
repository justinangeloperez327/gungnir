# Architecture Debt

This document records known limitations that should remain visible before a stable release.

- Suspended route handlers and `sleep_for` deadlines now share the HTTP platform readiness loop while the server is active; due continuations are dispatched through the bounded executor pool. Request cancellation propagates into database connection execution through scoped driver cancellation hooks. PostgreSQL and SQL Server implement native in-flight interruption; MySQL and MongoDB remain cooperative at the connection boundary. Storage operations expose cancellation-aware overloads with buffered LocalDisk checkpoints; other filesystem-backed framework components are not yet uniformly cancellation-aware.
- The HTTP server now closes its listener and gracefully drains already-dispatched requests before the configured shutdown deadline, then signals cancellation and closes remaining client sockets. Process-wide draining is not yet coordinated with queue workers, scheduler callbacks or arbitrary application coroutines. The server still does not establish production-grade HTTP/2, TLS, WebSocket or asynchronous streaming guarantees.
- Database runtime manager publication is atomic and transaction-scoped connection overrides are internal, thread-local, and restricted to synchronous thread-affine transaction closures. Async transactions remain unsupported until coroutine-local execution context and suspension-safe connection ownership are implemented.
- PostgreSQL, MySQL, SQL Server, and MongoDB have concrete client-library adapters. MongoDB replica-set transaction/session support remains incomplete.
- Parent-scoped ORM relationship queries cover direct, pivot and through relations. Many-to-many attach/detach/sync now execute real pivot mutations with transactional sync and rollback coverage. Broader concurrent relationship execution coverage remains incomplete.
- Session request lifecycle, cookie integration, CSPRNG identifiers, flash aging, regeneration, stale-ID cleanup, request-owned session authentication and session-bound CSRF protection are implemented. Redis provides a concrete distributed session store with TTL expiry and automatic Redis-side cleanup. Additional database-backed stores and advanced distributed lifecycle policies remain optional follow-up work.
- Cache, queue and sessions have concrete optional hiredis Redis adapters with live integration/package-consumer coverage. The Redis queue provides visibility leases, delayed delivery/release, lease renewal, retry backoff and failed-job administration. Mail has an optional libcurl SMTP/SMTPS/STARTTLS transport with live integration/package-consumer coverage. Redis Cluster/TLS/Sentinel/pooling and notification-specific production channels beyond mail remain incomplete.
- View runtime global engine state and filesystem symlink containment require hardening.
- Local storage rejects existing symlink traversal, canonicalizes containment, uses exclusive same-directory temporary files and atomically replaces completed writes. Race-free containment against concurrent hostile filesystem mutation and full crash-durable directory commits remain separate hardening work.
- Events currently use named polymorphic events rather than a fully typed dispatch surface.
- Queue visibility leasing, delayed delivery/release, crash recovery, reservation-token lease renewal, retry backoff and failed-job lookup/retry/delete are implemented. The generic worker has a long-running loop with cooperative stop/cancellation, idle polling, bounded-run options and optional lease heartbeats. Multi-process supervision remains incomplete.
- Scheduler provides interval and standard five-field cron execution, explicit fixed/recurring timezones, DST gap handling, repeated-wall-minute suppression, in-memory overlap locking, Redis owner-token distributed locks, and a deadline-aware production runner with cooperative cancellation/draining. A full external IANA timezone database adapter and process-wide runtime supervision remain incomplete.
- Logging provides structured records and sinks. A dependency-free tracing core now provides spans, parent/child context, executor propagation and exporter lifecycle hooks. Framework instrumentation, metrics instruments and production exporters remain incomplete.
- Plugin compatibility expressions are not yet parsed or enforced.
- Generated CLI scaffolding must remain synchronized with source-language lowering and runtime contracts.

These are release blockers only when the intended release claims the affected capability. They must not be hidden by documentation or marketing.
